# Решето Эратосфена
позволяет за $O(n*log(log(n)))$ находить простые числа до n.
## Принцип работы
Сделаем "решето" из чисел от 0 до n, все числа кроме 0, 1, 2 обозначим простыми
потом, будем перебирать делители. При нахождении простого числа можно вычеркнуть все числа,
кратные данному числу, начиная от данного числа в квадрате.
### Утверждение:
При нахождении простого числа $p$ можно "вычёркивать" начиная с квадрата это числа
### Доказательство:
Так как мы перебираем числа, кратные $p$, где $p$ - простое число, значит число $k$, которое
перебирается, является составным. Значит, у него есть делитель $k / p$.
Если $k / p \geq p$, значит $p \leq \sqrt k$, значит, мы можно перебирать от $p^2$.
Если $k/p < p$, то число $k$ "вычеркнули" обрабатывая до этого минимальный простой делитель $k / p$
### Реализация

```cpp
vector<bool> is_prime(n + 1, true);
is_prime[0] = is_prime[1] = false;
for (long long i = 2; i <= n; i++)
    if (is_prime[i]) {
        // число i - простое
        for (long long j = i * i; j <= n; j += i) {
            // число j - составное
            is_prime[j] = false;
        }
    }
```
