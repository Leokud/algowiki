# Префиксные суммы
Префиксными суммами массива a размером n называется массив p размера n+1
где
$$
\begin{align*}
& p_0 = 0 \\
& p_1 = a_0 \\
& p_2 = a_0 + a_1 \\
& p_3 = a_0 + a_1 + a_2 \\
& ... \\
& p_{n+1} = a_0 + a_1 + ... + a_n
\end{align*}
$$


$$
p_k = \sum_{\substack{0 \le i < k \\}} a_i
$$
префиксные суммы хранят сумму на полуинтервале $[0;i)$
получение суммы на полуинтервале за $O(1)$
## Вычисление суммы на отрезке
$sum [l; r) = sum [0; r) - sum [0; l)$
вычисление суммы на отрезке за $O(1)$
```cpp
vector<int> a(n), p(n + 1);
p[0] = 0;
for(int i = 0; i < n; i++){
	p[i+1] = p[i] + a[i];
}
// [l; r)
int pref_sum(int l, int r){
	return p[r] - p[l];
}
```
