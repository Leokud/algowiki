# Бинарный поиск
## Бинарный поиск
Основная идея бинарного поиска:  
Пусть есть массив $а$ длиной $n$, функция $f$ и число $k$,
при котором для каждого
$i \in [0;k)$ $f(a_i) = false$,  
а для каждого
$i \in [k; n)$ $f(a_i) = true$.  
Тогда можно заметить, что при выборе какого-то индекса $i$ если $f(a_i) = true$, тогда для всех $j \in [i;n)$ $f(a_j) = true$,  
а если $f(a_i) = false$, тогда для всех $j \in [0; i)$ $f(a_j) = false$.
## Бинарный поиск по массиву
Есть массив, который отсортирован по неубыванию,
и нам нужно найти индекс элемента $target$.
Можно итерироваться по массиву по каждому элементу, но это можно делать быстрее.  
В данном примере функция $f(x) = x \geq target$
```cpp
vector<int> a(n);
int target;
...
int l = 0, r = n - 1, ans = -1;
while (l <= r) {
    int m = l + (r - l) / 2;
    if (a[m] == target) {
        ans = m;
        break;
    }
    if (a[m] < target) {
        l = m + 1;
    } else {
        ans = m;
        r = m - 1;
    }
}
```
